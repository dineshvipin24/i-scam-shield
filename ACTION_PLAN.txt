    async def detect_voice(file: UploadFile = File(...)):
        audio_bytes = await file.read()
        prediction, probs = ai_voice_detector.predict_pcm(audio_bytes)
        return {
            "prediction": prediction,
            "confidence": max(probs.values()),
            "probabilities": {
                "human": probs["Human"],
                "ai_generated": probs["AI-Generated"],
                "deepfake_synthetic": probs["Deepfake/Synthetic"]
            }
        }

⚠️ COMMON ISSUES & QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

IF → THEN:

❌ Training fails
  → Check pip install worked: pip show torch
  → Make sure audio file exists
  → Try adding --help: python quick_train_ai_voice.py --help

❌ main.py won't import
  → Check file path is correct
  → Try: python -c "from backend.model.ai_voice_detector import AIVoiceDetector"
  → Make sure __init__.py exists in backend/ and backend/model/

❌ Git push fails
  → Check you're in right directory: pwd
  → Try: git status
  → Make sure you have internet connection

❌ Render build fails
  → Check logs: dashboard.render.com
  → Wait 5+ minutes (sometimes slow)
  → Try redeploying manually in dashboard

❌ Endpoint returns 404
  → Check URL spelling
  → Make sure main.py changes were pushed
  → Check Render deployment completed

❌ Slow response (>10 seconds)
  → First request: normal (1-2s for model load)
  → Check Render logs for errors
  → If persistent: upgrade to Render pro tier
