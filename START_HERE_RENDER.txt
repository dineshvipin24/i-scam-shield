STEP 2: UPDATE FastAPI CODE
───────────────────────────────────────────────────────────────────────────────

File: backend/main.py

Add these imports at the top:
┌─────────────────────────────────────────────────────────────────────────────┐
│ from backend.model.ai_voice_detector import AIVoiceDetector                │
│ ai_voice_detector = AIVoiceDetector()                                       │
└─────────────────────────────────────────────────────────────────────────────┘

Add this endpoint:
┌─────────────────────────────────────────────────────────────────────────────┐
│ @app.post("/api/detect-voice")                                             │
│ async def detect_voice(file: UploadFile = File(...)):                      │
│     audio_bytes = await file.read()                                        │
│     prediction, probs = ai_voice_detector.predict_pcm(audio_bytes)        │
│     return {                                                               │
│         "prediction": prediction,                                         │
│         "confidence": max(probs.values()),                                │
│         "probabilities": {                                                │
│             "human": probs["Human"],                                      │
│             "ai_generated": probs["AI-Generated"],                       │
│             "deepfake": probs["Deepfake/Synthetic"]                     │
│         }                                                                 │
│     }                                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

(Full code in: backend/FASTAPI_INTEGRATION.py)

Time: 2-3 minutes

TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

❌ Deployment hangs
   → Normal on free tier (wait 10+ minutes)
   → Check logs for errors

❌ Module not found error
   → Make sure you pushed all files: git add . && git push
   → Wait for Render to redeploy

❌ Model not found
   → Check ai_voice_model.pth exists locally
   → git add backend/model/ai_voice_model.pth
   → git push

❌ Slow response
   → First request: ~1-2s (model loads)
   → Next requests: ~300-500ms
   → This is normal!
